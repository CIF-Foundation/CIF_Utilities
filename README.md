# CIF_Utilities
Provide common utilities for LabVIEW development.  Especially helpful in real-time, embedded, and Linux development.

Functions are provided for:

- Library based error management.  Error reporting and conversion to human readable formats.
- Data type manipulation including performant data flatten and unflatten.
- Network helpers for workign with IPV4
- Statistics and benchmark tools designed for real-time operation.
- Time conversion functions.
- File utilities for path validation and OS conversion.
- Boolean operations for edge detection and latching, also useful for FPGA development.
